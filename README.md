How to use the profiles  

Windows  
Open Dolphin, go to File and click "Open User Folder"  
Go to /Config/Profiles/ and drag the profile to GCPad for Gamecube controllers and Wiimote for Wiimotes  
Since version 2509-349, you can access the folder containing the profiles directly from the controller mapping window by clicking on the arrow on the top right, then selecting "Open Folder"
